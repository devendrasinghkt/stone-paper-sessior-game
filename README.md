# Stone Paper Scissors Game

A simple and interactive **Stone Paper Scissors Game** built using **HTML, CSS, and JavaScript**. The project allows users to play against the computer with instant results and score tracking.

## 🛠️ Technologies Used

* **HTML** – For creating the structure of the game.
* **CSS** – For styling and designing the user interface.
* **JavaScript** – For game logic, user interaction, and computer choices.

## ✨ Features

* Play **Stone, Paper, Scissors** against the computer.
* **Random computer choice** for every round.
* Displays the **game result** instantly.
* Keeps track of the **user and computer score**.
* Simple and **easy-to-use interface**.
* **Responsive design** for different screen sizes.
* Interactive buttons for selecting Stone, Paper, or Scissors.

## 💻 How to Run

1. Download or clone the repository.
2. Open the project folder in **VS Code**.
3. Open `index.html` in your browser.
4. Start playing the game.

This project was created to practice **HTML, CSS, and JavaScript** concepts, especially JavaScript **logic, functions, conditions, DOM manipulation, and user interactions**.
